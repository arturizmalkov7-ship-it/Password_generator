# Tehnium

Это пробный проект, созданный для проверки структуры репозитория, настройки GitHub и базового запуска приложения.

## Модель

Используемая модель: MAI-Code-1.1-Flash

## Описание

Проект представляет собой стартовую структуру веб-приложения на Node.js. В текущем состоянии он содержит базовый HTTP-сервер и готов к дальнейшему развитию.

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите проект:
   ```bash
   npm start
   ```
3. Откройте в браузере:
   http://localhost:3000

## Структура проекта

- `server.js` — точка входа приложения
- `src/` — исходный код приложения
- `public/` — статические файлы
- `package.json` — настройки проекта и скрипты
